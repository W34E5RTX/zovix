# ZOVIX

Production-ready full-stack IT company platform.

## Overview

ZOVIX is a premium technology company website with a public marketing site, lead capture, and a protected admin dashboard for managing content and leads.

## Stack

- Frontend: React + Vite + Tailwind CSS
- Backend: Node.js + Express + MongoDB
- Admin: JWT-authenticated dashboard
- 3D: React Three Fiber + Drei + GSAP + Lenis

## Key Features

- Premium light-themed marketing site
- Scroll-driven 3D experiences
- SaaS and service sections
- Project portfolio management
- Lead capture and email notifications
- Admin authentication and role-based access
- CMS for projects, services, testimonials, clients, and site settings

## Quick Start

```bash
cd zovix/frontend
npm install
npm run dev
```

```bash
cd zovix/backend
npm install
cp .env.example .env
npm run dev
```

## Important

Demo admin credentials are provided only in the backend seed instructions and should be changed immediately in production.

## Deployment

- Frontend: Vercel
- Backend: Render or Railway
- Database: MongoDB Atlas
